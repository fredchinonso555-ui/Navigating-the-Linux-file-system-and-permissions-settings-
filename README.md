🐧 Navigating the Linux Filesystem and Permission Settings

Cisco CyberOps Practical Lab

This project documents a practical Linux filesystem and permissions exercise completed as part of my cybersecurity learning journey.

The lab focuses on understanding how Linux organizes files, manages storage devices, controls access permissions and handles different file types.

🎯 Lab Objectives

1. Explore Linux filesystems.
2. Identify storage devices and partitions.
3. Understand mounting and unmounting filesystems.
4. Examine Linux file permissions.
5. Change file permissions using "chmod".
6. Change file ownership using "chown".
7. Understand symbolic links and hard links.
8. Identify Linux special file types.

📚 Lab Structure

Part 1: Exploring Filesystems

- Identifying block devices.
- Examining mounted filesystems.
- Understanding root filesystems.
- Mounting and unmounting partitions.

Part 2: File Permissions

- Understanding read, write and execute permissions.
- Identifying file owners and groups.
- Using chmod to modify permissions.
- Using chown to change ownership.
- Understanding directory permissions.

Part 3: Symbolic Links and Special File Types

- Identifying Linux file types.
- Creating symbolic links.
- Creating hard links.
- Understanding inode relationships.
- Examining broken symbolic links.
